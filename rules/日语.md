# 日语场景规则

处理日语单词、短语、句子、语法，以及“中文或韩文内容 + 日语/일본어”的请求。所有解释、错误分析、用法说明和差异说明一律使用中文。

## 通用规则

- `日语`和`일본어`是完全等价的转换关键词；用户输入任意一个，都必须触发本规则。
- 先判断输入属于日语单词或短语、日语句子、日语语法，还是“中文或韩文内容 + 日语/일본어”请求。
- 保留用户原本想表达的意思、语气和礼貌程度。
- 中文和韩文对应表达必须自然，不得只做生硬的逐字翻译。
- **Markdown 强制硬换行**：为了防止 Markdown 渲染器将单换行自动合并，所有需要换行的文字行末（包括 `日语：` 标签行、表达行、读音行、中文词义行、对应韩文行、日文例句行等）**必须添加 `<br>` 标签实现硬换行**。
- **可复制纯文本编号**：凡是在义项、用法或说明中需要列出编号时，**严禁在行首直接写 `1. `，防止被 Markdown 解析为 HTML 有序列表导致复制时丢失数字**。编号必须写在加粗标记内部（例如 `**1. 着手/半成品**：...`）或使用带括号形式（例如 `**1）着手/半成品**：...`），确保复制粘贴时 100% 带有数字编号。
- 日语词条、短语、语法名称和推荐表达必须采用分行排版：第一行只写 `日语：<br>`（语法场景可写 `日语语法：<br>`，转换场景可写 `日语表达：<br>`），第二行单独用粗体写日语表达并跟上 `<br>`；表达含汉字时，第三行再单独用粗体写整个表达的平假名读音并跟上 `<br>`。
- 第二行的日语表达不得把平假名读音放在右侧括号中。例如不得写成 `日语：**一瞬で（いっしゅんで）**`，必须写成：
  ```
  日语：<br>
  **一瞬で**<br>
  **いっしゅんで**<br>
  ```
- 纯平假名或片假名表达不重复标注读音，只输出标签行和加粗的表达行。并列列出多个日语表达时，每个表达分别遵守上述排版。普通日语例句和完整句子不逐词标注，除非用户明确要求。
- 日语词条或表达之后，中文词义和对应韩文必须按“中文在前、韩文在后”的顺序各自单独成行（每行末尾加 `<br>`），直接输出内容，禁止添加 `中文：`、`韩文：` 标签。
- 用法、场景、语气等说明直接写说明内容，禁止在前面添加 `使用说明：` 标签。
- 每组例句先写日语（行末加 `<br>`），下一行紧接中文翻译。
- 两组日中例句之间必须使用标准的物理 Markdown 空行（连续两个回车 `\n\n`）分隔，绝对禁止使用 `ㅤ`（U+3164）等隐形占位字符。
- 要求两组例句时必须正好给出两组，不得只给一组。
- 回答中凡是列出多个语气层级、礼貌程度、活用变体、替代表达、对比形式或相关句型，每一个被列出的形式都必须分别给出两组日中例句，不得只列出表达及中文释义。
- 上述补充形式的每组例句同样遵守“一句日语（末尾加 `<br>`）＋下一行中文翻译”的格式，并在两组之间使用标准的物理 Markdown 空行（连续两个回车 `\n\n`）。

- **近义表达也需注明字典原形及中韩文释义**：不论是主词还是列出的近义表达/补充表达，只要其词条为活用形式（如过去形、否定形、被动形等），**必须在标注 `字典原形：...` 之后，在其下方紧接着各单独成行输出该字典原形的中文释义与对应韩文释义**（按中文在上、韩文在下各独占一排）。
- **例句展示字典原形的活用变形**：在给出两组例句时，例句中应根据该词的字典原形及其各种实际活用变形（如原形、过去形、否定形、接续形、可能形等）来灵活举例展示，帮助用户直观掌握该词的原形与活用变形用法。**绝对不要在例句末尾或括号内添加类似 `（活用变形：...）` 的解释性说明文字，保持例句与翻译简洁干净**。
- **语法场景的韩语对应需分行输出**：在【日语语法】场景中，**禁止添加 `对应韩语语法：` 前缀**；如果有多个对应或相近的韩语语法/表达，**必须每个各自单独成行输出**。
- **多词/多语法对比场景**：当用户一次性发送两个（或多个）日语单词、短语或语法表达时，除了必须将每个词/语法分别按标准格式排版并给出两组日中例句外，**必须专门单列部分用中文详细对比说明它们之间的语感、使用场景、书面语/口语或礼貌程度等差异**。若存在其他类似常用的表达，也必须一并列出，并同样遵守完整的排版格式、差异说明与两组例句的要求。
- **严禁跨语言字符混淆**：在输出韩文释义、韩文翻译或韩文语法时，**必须严格核对韩文字符，绝对禁止混入日语平假名/片假名**（例如严禁将韩文词尾 `다` 错写为日语假名 `だ`，或将韩文谚文混错）。在输出日文文本时也绝对禁止混入韩文谚文。输出前必须执行严格的多语言字符校验，确保字符纯正无误。
- **中文释义括号补充说明单列换行**：在输出中文词义或字典原形中文词义时，凡是包含括号内的词性、短语类型或语法补充说明（例如 `（连体形）`、`（名词/短语）`、`（汉字词）`、`（副词活用形）` 等），**禁止写在中文词义同排，必须换行单独成排输出**（按主中文词义在上一排、括号补充说明在下一排独占一行）。

## 日语单词或短语

用户发送一个日语单词或短语时：

1. 给出日语词条；含汉字时在下一行单独标注加粗的平假名读音。
2. 给出对应中文词义。
3. 给出对应韩文词语。
4. 如果输入是活用形式，补充其字典原形，并在下方单列两行给出字典原形的中文词义与对应韩文。
5. 如果存在多个常用义项，用中文简要区分。
6. 给出两组日中例句，例句中要体现字典原形及其活用的变形用法。
7. 主词解释之后，必须列出意义相近的其他常用日语表达，优先选择两个最常用、最实用的表达。
8. 每个近义表达必须分别给出日语词条、平假名读音、中文词义、对应韩文表达，**如果近义表达是活用形式，也必须标注其字典原形及在下方单列两行输出字典原形的中韩文释义**，并说明它与主词之间的语感或使用场景差异。
9. 每个近义表达必须分别给出两组日中例句（例句展现其原形及活用变形），两组之间同样使用 `ㅤ`（U+3164）占位空行，不得省略或共用主词的例句。

固定格式：

```text
日语：
**漢字を含む表現**
**ひらがなの読み**

中文词义
对应韩文

字典原形：...（若是活用形式时标注）
原形中文词义
原形对应韩文

日语例句
中文翻译
ㅤ
日语例句
中文翻译
```

近义表达固定格式：

```text
类似的常用日语表达：

日语：
**漢字を含む表現**
**ひらがなの読み**

中文词义
对应韩文

字典原形：...（若是活用形式时标注）
原形中文词义
原形对应韩文

区别：用中文说明与主词的语感或使用场景差异。

日语例句
中文翻译
ㅤ
日语例句
中文翻译
```

## 日语句子

用户发送一个日语句子时：

### 默认口语标准

- 除非用户明确要求书面语、正式语体或特定文体，否则一律以日本人实际交谈时自然使用的口语为修改标准。
- 保留「って」「じゃん」「ちゃう」「てる」等自然口语形式，不得仅为符合书面规范而擅自改成正式、生硬的表达。
- 重点纠正实际口语中不自然或错误的语法、助词、活用、搭配和用词。
- 如果原句在口语中成立，必须明确说明“口语自然”，不得强行修改。
- 必要时可以补充更随意或更地道的口语说法，并说明语感差异。

1. 原样列出用户的句子。
2. 先用中文指出语法、助词、活用、搭配、词汇、语体或自然度方面的问题。
3. 如果没有明确错误，说明原句正确，并把可选的自然度优化与语法纠错误区分开。
4. 根据用户原意润色成自然、准确的日语表达。
5. 用中文简要解释主要修改点。

固定格式：

```text
原句：...

问题：
- ...

自然表达：...

修改说明：...
```

## 日语语法

用户发送日语语法形式或询问日语语法时：

1. 列出日语语法；核心部分含汉字时在下一行单独标注加粗的平假名读音。
2. 列出对应或最接近的韩文语法（有多个时每个各自独占一行，禁止加 `对应韩语语法：` 前缀）。
3. 用中文说明含义、接续方式、使用场景、语体和重要语感。
4. 如果不存在完全一一对应的韩文语法，明确说明，并列出最接近的语境对应形式。
5. 给出两组日中例句。

固定格式：

```text
日语语法：
**漢字を含む文法**
**ひらがなの読み**

对应韩语语法1
对应韩语语法2

中文解释：...

日语例句
中文翻译
ㅤ
日语例句
中文翻译
```

## “中文或韩文内容 + 日语/일본어”请求

用户发送中文或韩文内容，并在内容后附加“日语”或“일본어”作为转换标记时，必须触发本规则，不得套用韩语的 `rules/表达.md`。两个关键词的处理方式完全相同。

1. 判断用户想表达的真实含义和使用场景。
2. 列出最常用、最自然的日语表达；含汉字时必须在下一行单独标注加粗的平假名读音。
3. 同时列出对应的中文表达和韩文表达。
4. 用中文说明日语表达的接续方式、适用场景、礼貌程度和重要语感。
5. 每个列出的日语表达分别给出两组日中例句。
6. 最自然的表达放在最前面。只有在语感或使用场景存在明显差异时，才补充其他常用表达。

每个表达使用以下格式：

```text
日语表达：
**漢字を含む表現**
**ひらがなの読み**

中文词义
对应韩文

...

日语例句
中文翻译
ㅤ
日语例句
中文翻译
```

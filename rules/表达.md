# 表达场景规则

用户给出一个中文表达，列出对应的韩语常用说法。

所有解释说明一律用中文，不得混入韩文。例句部分才出现韩文。

## 格式

1. 列出所有常用韩语对应表达，每个表达：
   - **Markdown 强制硬换行与防行合并铁律**：所有需要分行的标题、表达行、词性与释义行、读音行、差异说明行以及韩文例句行末尾**必须添加 `<br>` 标签实现硬换行**，绝对严禁依赖单个普通换行（防止被 Markdown 自动强行合并到同一行）。
   - 字典式简短释义必须分三行排版：第一行为韩文表达（末尾加 `<br>`），第二行为词性与中文释义（末尾加 `<br>`），第三行为实际读音（末尾加 `<br>`），各单独成行。
   - 用中文说明该表达的含义和使用场景。
   - 说明各表达之间的使用区别。
   - 给出两组中韩例句：
     - 每组：一句韩文（末尾加 `<br>`） + 紧接一句中文翻译，中韩之间 0 空行。
     - 两组例句之间必须使用标准的物理 Markdown 空行（连续两个回车 `\n\n`）分隔，绝对禁止使用 `ㅤ`（U+3164）等隐形占位字符。
     - 例句不加编号。

## 补充表达规则

- 回答中凡是出现“更自然的表达”“类似表达”“相关表达”“替代表达”或其他补充推荐表达，每个表达都必须分别给出两组中韩例句。
- 不得只列出韩语表达及其中文释义。即使补充表达出现在回答末尾，也必须完整提供两组例句。

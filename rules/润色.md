# 润色场景规则

进行韩语润色，要求口语化、自然，像韩国人常用的表达方式。

- 输入是中文 → 直接翻译成自然韩文
- 输入是韩文 → 基于原文直接润色

## 原句纠错

输入是韩文时，必须先检查原句是否存在拼写、语法、助词、词尾、时态、敬语、搭配或语境方面的错误。

- 如果原句有错误：除给出润色后的自然表达外，还必须逐项指出错误位置，用中文解释错误原因，并给出对应的正确形式。不得只输出修改结果。
- 如果原句没有错误但表达不够自然：必须明确说明原句语法正确，再用中文分析不自然或不符合常用口语习惯之处。
- 如果原句正确且自然：明确说明原句没有问题；如提供其他表达，须说明只是语气或风格上的替换，并非纠错。
- 必须区分“语法错误”和“表达自然度问题”，不得把单纯的表达偏好说成错误。

# 变更影响分析：到期复习与主动回忆

## 问题与完成标准

- 问题：现有卡片复习缺少到期安排、主动输入、错词回炉、范围选择和例句填空。
- 用户可观察结果：复习页可启动“今日复习”或自定义自由复习；支持翻卡、释义写词、听写、例句填空和混合题；错误词本轮回炉。
- 明确不在范围内：不接入外部语音评分服务，不自动生成例句，不自动建立相近表达，不改动资料库。
- 完成标准：五项功能在 KR/JP 镜像可用；学习状态耐久保存并进入逐字段云同步；旧词无损兼容；自动化与质量门禁全部通过。

## 风险与回滚

- 数据兼容风险：旧词没有 `srs`；采用惰性默认值，首次评分后才写入。未知 `srs` 扩展字段随对象保留。
- 并发或跨设备风险：SRS 作为单个逐字段字段以 `fieldUpdatedAt.srs` 冲突合并；最后一次评分时间较新者获胜。
- 安全与隐私风险：仅保存学习时间和结果，不增加外部请求或录音存储。
- 回滚方法：回滚 ADR-021 对应提交即可恢复旧 UI；已经保存的 `srs` 字段会被旧代码忽略，不影响词条正文。

## 验证计划

- 新增或更新的测试：双端 DOM 镜像、SRS 默认/四级调度、今日队列新词上限、自定义范围、五种题型、输入判分、例句安全遮盖、错词 3 卡后回炉及 2 次上限、云同步字段。
- 必须运行的质量门禁：`python scripts/run_quality_gate.py`
- 部署后验证：远端提交一致；GitHub Pages 的 KR/JP 页面包含 `reviewSessionSetup`、`startTodayReviewSession` 与 `reviewAnswerInput`。

# 项目知识地图

| 变更主题 | 主要入口 | 下游消费者 | 核心测试 |
|---|---|---|---|
| 单词字段 | 编辑弹窗保存逻辑 | 本地存储、云端 payload、四类展示视图 | 字段持久化、缓存升级、双端浏览器测试 |
| 排序与筛选 | `renderWordList`、复习会话初始化 | 分页、统计、空状态、滚动位置 | 排序分发、真实页面顺序、统计一致性 |
| 相近表达 | 人工关系增删方法 | 详情、复习背面、反向词条 | 双向添加、双向删除、旧数据迁移 |
| 本地存储 | `SafeStorageWrapper`、IndexedDB | 启动加载、所有编辑入口 | 存储失败、重载恢复、成功反馈门禁 |
| 云同步 | Supabase 同步方法集 | 待上传队列、版本元数据、删除墓碑 | 双设备、分页、并发、残缺快照 |
| 页面布局 | `tab-list`、`wordList`、`paginationBar` | 滚动、空结果、底部导航 | DOM 契约、尺寸、真实滚动 |

## 人类判断节点

- 数据迁移是否允许不可逆转换。
- 云端与本机发生真实内容冲突时的产品策略。
- 新架构是否继续满足单文件离线交付。
- 会影响用户已有数据的删除、覆盖和回滚决定。

其余可重复检查应交给质量门禁自动执行。

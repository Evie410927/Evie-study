# 本地学习资料库变更影响分析

## 问题与完成标准

- 问题：单词本没有集中保存和再次打开 PDF、Word、Excel 等学习资料的入口。
- 用户可观察结果：顶部新增资料图标；点击后可批量上传、查看/打开、下载和删除文件，并看到文件类型、大小与添加时间。
- 明确不在范围内：资料文件不参与 Supabase 云同步、词库备份导出、全文解析或内容搜索。
- 完成标准：KR/JP 镜像实现；文件经 IndexedDB 持久化；不支持类型与超限文件被拒绝；持久化成功后才提示成功；双端自动化和质量门禁全部通过。

## 影响范围

- [x] KR 应用
- [x] JP 应用
- [x] 数据字段或缓存迁移（新增独立附件库，无词条迁移）
- [x] localStorage / IndexedDB（仅新增独立 IndexedDB）
- [ ] 云端 payload / RLS / 版本协议
- [ ] 列表 / 详情 / 复习 / 相近表达
- [x] 移动端与空状态
- [x] 现有规则或 ADR

## 风险与回滚

- 数据兼容风险：旧版本不会读取附件库，但不会删除或改写其中的文件。
- 并发或跨设备风险：本条已被 ADR-012 与 ADR-015 取代；资料现支持云同步，并在同源环境按 KR/JP 语言分区。
- 安全与隐私风险：限制文件白名单，不渲染 HTML/SVG/脚本；Blob 只在用户主动打开时生成临时 URL 并及时回收。
- 回滚方法：移除资料库 UI 与运行时代码即可；独立 IndexedDB 可保留，避免误删用户已上传文件。

## 验证计划

- 新增或更新的测试：双端静态结构与契约；真实浏览器打开弹窗、上传、持久化读取、打开/下载、删除和空状态。
- 必须运行的质量门禁：`python scripts/run_quality_gate.py`
- 部署后验证：确认 GitHub Pages 两端均出现资料按钮，弹窗可打开且本地保存边界说明可见。

# ADR-004：相近表达按源词条独立持久化自定义顺序

- 状态：Accepted
- 日期：2026-09-29

## 背景

相近表达关系是双向的，但用户在不同词条中关注的先后顺序可能不同。详情弹窗和复习背面此前只能按添加顺序展示，无法直接调整优先级。

## 决策

1. `manualSimilarWordIds` 的数组顺序同时作为当前源词条的相近表达展示顺序。
2. 详情弹窗与复习背面使用同一顺序，并允许直接拖动整张相近表达卡片排序。
3. 不增加拖拽按钮或手柄；鼠标可直接拖动，触屏长按卡片后拖动，短按仍打开词条详情。
4. 卡片内的删除、掌握状态和星级控件不触发拖拽。
5. 排序只更新当前源词条的数组顺序。双向关系仍然保留，但反向词条拥有独立顺序。
6. 排序成功后更新用户编辑时间、持久化到本地并进入现有云同步待上传机制。

## 验证

- 静态测试确认整卡拖拽事件、无额外拖拽控件、顺序持久化与交互控件隔离。
- Selenium 分别在详情和复习视图执行排序，验证两处顺序同步、本地存储更新以及重绘后顺序保持。
- KR 与 JP 两端执行完全相同的断言和完整质量门禁。

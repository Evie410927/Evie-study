# ADR-008：词性筛选下拉框提供固定的一键重置入口

- 状态：Accepted
- 日期：2026-10-09

## 背景

列表页的词性筛选支持多选，但用户选中若干词性后，下拉框内没有可见的一键清空入口。现有运行时虽已具备 `clearAllPartOfSpeechFilters()`，用户仍需逐项取消，选项较多时操作成本高，也不容易快速回到显示所有词性的默认状态。

## 决策

1. 在 `#partOfSpeechDropdownMenu` 底部增加唯一的 `#partOfSpeechDropdownResetBtn`，文案为“重置（显示全部）”。
2. 重置按钮必须紧随 `#partOfSpeechDropdownList`，位于独立固定底栏；词性选项继续在自身容器内滚动，按钮不得随列表滚出可视区域。
3. 点击按钮调用既有 `clearAllPartOfSpeechFilters()`，清空 `selectedPartOfSpeech`、把 `currentPage` 重置为 `1`，并立即刷新列表、Badge 和选项勾选状态。
4. 重置只作用于词性筛选，不清空搜索词、主状态筛选或自定义 Tag，避免一个局部控件意外破坏其他筛选上下文。
5. 韩语与日语页面使用完全相同的 DOM ID、CSS 类、交互逻辑和自动化测试。

## 验证

- 契约检查确认按钮位于词性列表之后并绑定正确方法。
- 静态测试确认双端包含固定底栏、按钮和镜像样式。
- 真实浏览器测试先选中多个词性，再点击按钮，验证选择集合、Badge、勾选状态和过滤结果全部恢复为显示所有词性。
- 完整质量门禁覆盖双端页面与移动端浮层高度约束。

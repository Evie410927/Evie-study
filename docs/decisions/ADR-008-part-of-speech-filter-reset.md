# ADR-008：词性筛选下拉框提供固定的一键重置入口

- 状态：Accepted
- 日期：2026-10-09

## 背景

列表页的词性筛选支持多选，但用户选中若干词性后，若下拉框内或收起状态下没有可见的一键清空入口，用户就需要逐项取消或再次展开列表。现有运行时虽已具备 `clearAllPartOfSpeechFilters()`，仍需为展开和收起两种状态都提供直接入口，才能快速回到显示所有词性的默认状态。

## 决策

1. 在 `#partOfSpeechDropdownMenu` 底部增加唯一的 `#partOfSpeechDropdownResetBtn`，文案为“重置（显示全部）”。
2. 重置按钮必须紧随 `#partOfSpeechDropdownList`，位于独立固定底栏；词性选项继续在自身容器内滚动，按钮不得随列表滚出可视区域。
3. 在 `#partOfSpeechDropdownBtn` 右侧增加独立的 `#partOfSpeechQuickResetBtn`。仅当已选词性数量大于 0 时显示，数量归零时隐藏，使下拉框收起后仍可直接重置。
4. 两个重置入口都调用既有 `clearAllPartOfSpeechFilters()`，清空 `selectedPartOfSpeech`、把 `currentPage` 重置为 `1`，并立即刷新列表、Badge、快捷按钮和选项勾选状态。
5. 重置只作用于词性筛选，不清空搜索词、主状态筛选或自定义 Tag，避免一个局部控件意外破坏其他筛选上下文。
6. 韩语与日语页面使用完全相同的 DOM ID、CSS 类、交互逻辑和自动化测试。

## 验证

- 契约检查确认底部按钮位于词性列表之后、快捷按钮位于收起触发按钮右侧，且两者绑定相同重置方法。
- 静态测试确认双端包含固定底栏、快捷按钮、按数量显隐逻辑和镜像样式。
- 真实浏览器测试先选中多个词性并收起列表，验证快捷按钮可见；点击后验证选择集合、Badge、按钮显隐、勾选状态和过滤结果全部恢复为显示所有词性。
- 完整质量门禁覆盖双端页面与移动端浮层高度约束。

# ADR-006：列表卡片阅读内容与低频底栏的纵向层级

- 状态：Accepted
- 日期：2026-09-29

## 背景

列表卡片底部的自定义 Tag 与操作按钮使用频率低于词性释义、单词说明和例句，但旧布局为底栏保留了较大的上间距与内距；与此同时，释义、说明和例句之间过于紧密，阅读层级不够清楚。

## 决策

1. 列表卡片中，词性释义到非空 `userNote` 说明的可见间距固定为 8px；说明到例句预览的可见间距固定为 10px。
2. 没有 `userNote` 时继续沿用释义到例句的既有间距，不制造空说明占位。
3. `.word-footer` 保持 Tag 左置、操作按钮右置的单行结构，完整保留自定义 Tag、行内 `+`、发音、编辑与删除入口。
4. 底栏改为 6px 上间距、4px 上内距和 8px 横向分区间距；空 Tag 状态下的基础控件高度控制在 18–22px，基础底栏可见高度不超过约 27px。
5. 列表底栏内的 Tag、删除小叉、加 Tag 按钮和三个操作按钮使用作用域内的紧凑尺寸；详情、复习及编辑弹窗中的同名组件不受影响。
6. Tag 数量较多时仍允许自然换行，绝不通过裁切或隐藏降低高度；紧凑规则只约束单行基础状态。

## 验证

- 静态测试确认正文两段间距、底栏 margin/padding/gap 及作用域内控件尺寸在 KR/JP 两端完全一致。
- Selenium 在无 Tag 的列表卡片中实测释义到说明约 8px、说明到例句约 10px，底栏基础高度不超过 27px，同时确认 Tag 与操作入口完整存在。
- 执行完整质量门禁并核验 GitHub Pages 双端部署内容。

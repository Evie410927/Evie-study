# ADR-007：新建词条的词性候选列表从顶部展开

- 状态：Accepted
- 日期：2026-09-30

## 背景

新增/编辑词条弹窗复用同一个 `#partOfSpeechOptions` 候选容器。浏览器会保留该容器上一次关闭前的内部滚动位置，因此新建词条时再次展开完整候选列表，可能直接停在列表底部，尤其在手机浏览器上不便从首项开始浏览。

## 决策

1. 新建词条模式下，每次通过词性输入框或右侧箭头展开完整候选列表，都将 `scrollTop` 与 `scrollLeft` 重置为 `0`。
2. 重置先在列表取消隐藏后同步执行，再通过下一次 `requestAnimationFrame` 复核一次，以抵抗移动端布局完成后恢复旧滚动位置的行为。
3. 只有“新建模式＋完整列表展开”触发该归零；用户输入关键词后的实时筛选继续正常工作，不打断输入过程。
4. 编辑既有词条时继续保留表单中回填的词性值，不因滚动归零规则被清空或改写。
5. 韩语与日语页面使用完全相同的 DOM 判定、滚动归零逻辑和测试断言。

## 验证

- 静态测试确认双端完整列表展开路径包含新建模式判定及同步/下一帧滚动归零。
- 真实浏览器测试先把候选列表滚到底部，关闭后重新展开新建词条列表，并验证其回到 `scrollTop = 0`、`scrollLeft = 0`。
- 完整质量门禁继续覆盖词性筛选、编辑回填、弹窗滚动和双端镜像规则。

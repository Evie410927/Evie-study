# ADR-019：非空搜索默认覆盖全部学习状态

- 状态：Accepted
- 日期：2026-10-26

## 背景

应用默认停留在“学习中”。用户直接搜索已掌握词条时，即使词条字段匹配，也会被主状态筛选排除，形成“明明存在却搜不到”的误解。

## 决策

1. `onSearchInput()` 得到非空查询后，先调用统一入口把 `currentFilter` 设置为 `all`，并只激活 `data-filter="all"` 的主筛选按钮。
2. 自动切换只影响学习状态主筛选；词性、Tag 等用户明确选择的次级筛选保持不变。
3. 搜索仍回到第一页并沿用既有字段隔离范围。清空关键词后保留“全部”状态，不恢复搜索前筛选。
4. KR/JP 使用相同方法、DOM 状态与测试。

## 验证

- 静态契约检查非空搜索调用、`currentFilter='all'` 与按钮激活同步。
- Selenium 从“学习中”开始搜索同名的学习中和已掌握测试词，验证两张卡片都显示、“全部”按钮激活，并验证清空后仍停留在“全部”。

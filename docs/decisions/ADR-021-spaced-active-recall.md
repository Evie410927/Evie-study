# ADR-021：到期复习与主动回忆会话

- 状态：Accepted
- 日期：2026-11-11

## 背景

现有卡片复习只按创建时间或星级浏览，并用“易忘 / 记住了”二元反馈改变学习状态。它适合自由翻卡，但不能按遗忘时间安排复习，也不能检验从中文、声音或例句主动产出目标词的能力。

## 决策

1. 保留 ADR-002 的四种自由复习排序；新增独立“今日复习”会话，按 `srs.nextReviewAt` 到期时间升序出卡，不把到期顺序加入原排序下拉框。
2. 每个词允许保存 `srs` 对象：`nextReviewAt`、`lastReviewedAt`、`intervalDays`、`ease`、`repetitions`、`lapseCount`、`correctStreak`、`lastResult`。旧词缺少该对象时按未安排处理，不做整库破坏性迁移。
3. 今日队列包含全部已到期词，以及最多 10 个尚未安排且仍在学习中的新词；已到期词不得被新词上限截断。
4. 复习反馈固定为“忘记、模糊、记住、熟练”四级。反馈更新 SRS、逐字段时间戳、本地耐久快照和云同步待办。
5. 主动回忆模式提供翻卡、看释义写词、例句填空和混合模式，不提供听音写词。例句填空只在现存例句包含词条原文时遮盖原文；否则回退到看释义写词，不猜测活用形。普通朗读按钮继续保留。
6. 输入题严格比较清理首尾空白后的词条正文；答错或“忘记 / 模糊”在约 3 张卡后回炉，同一词每轮最多回炉 2 次。
7. 自由复习允许按状态范围、单个 Tag、词性、精确星级和 10/20/50/全部数量组合筛选；相近表达关系不参与任何出卡排序或自动关联。

## 兼容与同步

- `srs` 作为词条 payload 的普通逐字段合并字段，随现有 localStorage、IndexedDB、JSON/HTML 导出和 Supabase `payload` 同步。
- 缺失、非法或未来时间异常值在读取时通过非破坏性的默认值归一化；未发生复习时不主动写回旧词。
- KR/JP 使用相同 DOM、样式、算法和字段，仅保留既有语言文字、发音 locale 与 JP `krMeaning` 特例。

## 验证

- 静态契约检查双入口、四种题型、筛选项、四级反馈、SRS 字段与错词回炉上限，并确认听音写词入口与分支均不存在。
- 浏览器测试验证今日队列、自由筛选、输入判分、例句回退、回炉位置、持久化与 KR/JP 镜像。
- 完整运行 `python scripts/run_quality_gate.py`。

# ADR-016：词库筛选导出 Excel

- 状态：Accepted
- 日期：2026-10-21

## 背景

用户需要从 Header 直接把词库导出为 Excel，并在导出前选择全部、学习中、已掌握或指定 Tag。导出文件必须有清晰表头、基础样式、单元格换行，且每个词只包含第一组例句。

## 决策

1. Header 新增 `#exportExcelBtn`，固定放在 `#quickAddBtn` 左侧；资料库按钮相应位于导出按钮左侧。KR/JP 的 DOM、样式和交互保持镜像。
2. 点击按钮打开 `#excelExportModal`。导出范围是互斥的“全部、学习中、已掌握、按 Tag”；按 Tag 时允许多选，并采用匹配任一已选 Tag 的 OR 语义。没有选择 Tag 时禁止导出。
3. 浏览器直接生成标准 Office Open XML `.xlsx`，使用无压缩 ZIP 容器，不依赖网络或第三方库，维持 standalone 离线能力。
4. 工作表固定四列：单词、词性、释义、例句。表头使用粗体、白字和主题色填充；数据单元格支持自动换行和边框。
5. KR 释义单元格只写 `meaning`；JP 释义单元格先写中文 `meaning`，非空 `krMeaning` 在同一单元格下一行显示。不得把读音、备注或 Tag 混入这些列。
6. 例句单元格仅使用词条第一组现存例句，按“外文原句 + 换行 + 中文翻译”写入；其余例句绝不导出。没有例句时保持空单元格。
7. 导出使用当前内存词库与当前持久化编辑结果，不修改词条、筛选状态、时间戳或云同步待办。筛选后无数据时中止并给出明确提示。

## 验证

- 静态契约检查按钮相邻关系、弹窗范围选项、Tag 多选、四列表头、JP 分行释义、第一例句策略与 Open XML/ZIP 生成标记。
- Selenium 分别验证全部、学习中、已掌握和 Tag 筛选结果，并解析下载的 `.xlsx` ZIP，确认表头样式、行数、JP 中韩释义换行及仅第一组例句。

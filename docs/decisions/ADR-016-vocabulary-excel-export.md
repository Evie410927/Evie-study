# ADR-016：词库筛选导出 Excel

- 状态：Accepted
- 日期：2026-10-21

## 背景

用户需要从 Header 直接把词库导出为 Excel，并在导出前选择全部、学习中、已掌握、指定 Tag 或指定星级，也需要在浏览器支持时自行选择文件保存位置。导出文件必须有清晰表头、基础样式、单元格换行，且每个词只包含第一组例句。

## 决策

1. Header 新增 `#exportExcelBtn`，固定放在 `#quickAddBtn` 左侧；资料库按钮相应位于导出按钮左侧。KR/JP 的 DOM、样式和交互保持镜像。
2. 点击按钮打开 `#excelExportModal`。导出范围是互斥的“全部、学习中、已掌握、按 Tag、按星级”；按 Tag 时允许多选，并采用匹配任一已选 Tag 的 OR 语义；按星级时允许从无星到五星多选，并采用精确匹配任一已选星级的 OR 语义。相应自定义范围没有任何选择时禁止导出。
3. 浏览器直接生成标准 Office Open XML `.xlsx`，使用无压缩 ZIP 容器，不依赖网络或第三方库，维持 standalone 离线能力。
4. 弹窗统一展示单词、词性、释义、例句、发音、发音备注、说明、相近词汇八个列复选框。前四列默认勾选，后四列默认不勾选；用户可以自由取消或追加，但至少必须保留一列。表头使用粗体、白字和主题色填充；列宽、筛选范围和单元格地址必须随最终列数动态生成，数据单元格支持自动换行和边框。
5. KR 释义单元格只写 `meaning`；JP 释义单元格先写中文 `meaning`，非空 `krMeaning` 在同一单元格下一行显示。不得把读音、备注或 Tag 混入这些列。
6. 例句单元格仅使用词条第一组现存例句，按“外文原句 + 换行 + 中文翻译”写入；其余例句绝不导出。没有例句时保持空单元格。
7. 导出使用当前内存词库与当前持久化编辑结果，不修改词条、筛选状态、时间戳或云同步待办。筛选后无数据时中止并给出明确提示。
8. `#excelExportChooseLocation` 默认开启。支持 File System Access API 的浏览器通过系统“另存为”选择器写入 `.xlsx`；用户取消时不下载、不关闭弹窗。浏览器不支持时回退到浏览器管理的默认下载，并明确提示无法自定义位置；关闭选项时直接使用默认下载。
9. 相近词汇列只读取用户手动维护且当前有效的 `manualSimilarWordIds` 关系，保持当前词条的人工顺序；同一单元格内每行固定为“相近词：中文释义”。JP 同样只读取相近词的中文 `meaning`，不得输出 `krMeaning`。关联词的读音、发音备注、说明、词性、Tag、例句、星级和状态均不得混入该单元格。

## 验证

- 静态契约检查按钮相邻关系、弹窗范围选项、Tag/星级多选、八列复选框及默认状态、保存位置控件、JP 分行释义、第一例句策略与 Open XML/ZIP 生成标记。
- Selenium 分别验证全部、学习中、已掌握、Tag 和星级筛选结果，并解析默认四列、自定义取消默认列及全选八列的 `.xlsx` ZIP，确认零列阻止导出、动态列数、表头样式、JP 中韩释义换行、仅第一组例句，以及相近词汇单元格只含逐行“单词：中文释义”；另验证文件选择器成功、取消与不支持时的回退路径。

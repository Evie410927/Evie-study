# ADR-013：云同步前快照与可撤销历史

- 状态：Accepted
- 日期：2026-10-16

## 背景

词库云同步允许用户单独选择“上传当前本地版本”或“同步云端最新内容”。前者会把云端独有词条写成删除墓碑，后者会用云端内容替换当前浏览器并清空本地待上传变更。现有 IndexedDB 耐久快照只保存最新运行状态，云端 `__sync_meta__` 也只保存当前 revision；它们用于启动恢复和并发门禁，不能恢复一次已经完成的误操作。

## 决策

每次执行任何词库上传、下载或双向同步时，必须先成功读取云端完整词库，并在独立的 IndexedDB 历史键中原子保存一份同步前快照。快照必须同时包含：

1. 本地完整词库、待上传字段、删除墓碑和云端基线；
2. 云端完整数据行及同步前 revision；
3. 操作类型、语言、设备、创建时间和稳定快照 ID。

历史最多只保留最近 2 份；读取旧版存量历史时，必须立即裁剪并持久化最近 2 份。新快照写入失败时不得继续执行词库同步。学习资料同步保持独立，不进入词库撤销历史。

云同步弹窗固定提供“撤销上次变更”和“版本历史”入口。撤销入口只在存在有效快照时启用；历史视图显示每份快照的时间、操作类型及本地/云端有效词条数量。Excel 回导同样必须在任何词库改写前把本地完整状态作为“Excel 导入”快照写入同一个历史键并遵守最近 2 份上限；未捕获云端行的导入快照明确标记为仅本地版本。恢复必须先展示影响摘要，并明确区分：

- 只恢复本浏览器：恢复快照中的本地词库、待上传字段、删除墓碑和原云端基线，不修改云端；
- 恢复本地与云端：先读取当前云端状态，将快照中原有云端活动词条以新的更新时间重新写入，将快照中原有墓碑重新传播，并为当前云端新增但快照中不存在的词条写入新墓碑；随后创建单调递增的新 revision，再恢复快照中的本地状态并以该新 revision 持久化基线。

仅本地导入快照不得启用“恢复本地与云端”，避免把未捕获的空云端状态误当成真实版本；用户仍可从云朵入口选择“只恢复到本浏览器”回到导入前状态。

恢复云端不允许倒退 revision。恢复过程中不得覆盖或删除所选历史快照；失败时保留快照并报告错误，成功后刷新列表、统计与撤销入口。快照只保存在当前浏览器的 IndexedDB，不进入 `localStorage`、词库导出、`vocab_items` 或资料库。

## 验证

- 静态契约检查 KR/JP 均具有相同的撤销按钮、历史按钮、确认弹窗、2 份上限、旧历史裁剪和同步前快照门禁。
- 浏览器回归验证同步弹窗入口状态、同步前本地/云端复合快照、仅恢复本地、恢复本地与云端、新 revision 递增以及失败后历史保留。
- 验证纯学习资料同步不创建词库快照，KR/JP 的 DOM、方法和行为镜像一致。
- 运行完整质量门禁并在部署后确认线上页面包含撤销入口与快照逻辑。

# ADR-005：列表卡片原位维护个人记忆备注

- 状态：Accepted
- 日期：2026-09-29

## 背景

词条已有 `userNote` 自定义说明字段，但此前只能进入完整编辑弹窗维护。用户在浏览词表时需要快速记录容易混淆的记忆方式，并希望直接从当前单词卡片新增和删除，不增加大按钮或弹窗步骤。

## 决策

1. 继续使用 `userNote` 作为唯一记忆备注字段，不新增平行字段或数据迁移。
2. 列表卡片在红色读音之后紧邻显示约 15px 的弱化圆形 `＋`；点击后直接在标题同一排展开紧凑单行输入框，不使用 `prompt` 或额外弹窗。
3. 每次打开的输入框必须完全空白，不回填旧备注且不显示 placeholder；非空新内容追加到已有备注，空内容失焦不得清除旧备注。
4. 输入框按 Enter 或失焦保存，按 Escape 取消；需要完整修改已有备注时仍使用卡片编辑弹窗。
5. 非空备注继续使用原有中括号紧凑样式，并仅在列表卡片的备注末尾显示小型 `×`，点击后直接删除并持久化。
6. `＋`、输入框与 `×` 均阻断卡片详情点击，不能误开详情或触发其他操作。
7. 新增、修改和删除统一更新时间、用户编辑时间与 `userNote` 字段时间，复用现有 localStorage、IndexedDB 和云同步待上传机制；保存失败不显示成功。
8. 详情、复习和相近表达仍只读展示同一字段，完整编辑弹窗继续保留说明输入框。

## 验证

- 静态测试校验控件位置、同排空白输入、500 字符总长度约束、事件隔离和持久化调用。
- Selenium 在 KR/JP 两端实际执行点击 `＋`、输入保存、刷新重绘、再次修改、点击 `×` 删除，并检查本地存储与云同步待处理字段。
- 执行完整质量门禁并核验 GitHub Pages 双端部署内容。

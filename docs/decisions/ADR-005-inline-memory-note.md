# ADR-005：列表卡片原位维护独立发音备注

- 状态：Accepted
- 日期：2026-09-29

## 背景

词条已有 `userNote` 自定义说明字段，用于卡片下方 `【…】` 单词内容解释。用户还需要在红色读音旁单独记录发音或容易混淆时的个人记忆方式；这不是内容说明，生命周期必须完全独立。

## 决策

1. 新增独立字段 `pronunciationNote` 存放标题行发音/记忆提示；`userNote` 只存放下方中括号内容说明。两字段不得互相回填、覆盖、清空或迁移。
2. 列表卡片在标题行红色读音之后紧邻显示约 15px 的弱化圆形 `＋`；详情弹窗把红色读音和同一套发音备注控件放入标题下方、词性与释义上方的独立第二行。点击后直接在各自当前行展开紧凑单行输入框，不使用 `prompt` 或额外弹窗。
3. 点击 `＋` 打开的输入框必须完全空白且不显示 placeholder，非空新内容追加到 `pronunciationNote`；点击已有发音备注文字时，同一输入框回填当前完整内容，保存后以编辑结果替换旧值。
4. 两种模式均按 Enter 或失焦保存、按 Escape 取消；空内容失焦不得清除旧值，删除仍只由明确的 `×` 操作完成。
5. 非空 `pronunciationNote` 在列表标题行或详情独立发音行紧邻入口显示，并在末尾提供小型 `×` 直接删除；`userNote` 继续使用原有中括号样式，不因本功能新增行内删除入口。
6. `＋`、输入框、已有备注文字与 `×` 均阻断卡片详情点击。`＋`、已有备注文字和 `×` 在 `pointerdown` 阶段只执行 `stopPropagation()`，不得打开编辑器、隐藏、替换或删除自身；DOM 变更必须等其自身 `click` 事件明确命中后执行，防止移动端合成 `click` 因标题行提前重排而重定向到卡片并误开详情。
7. 新增、修改和删除统一更新时间、用户编辑时间与 `pronunciationNote` 字段时间，复用现有 localStorage、IndexedDB、导入导出和云同步待上传机制；保存失败不显示成功。
8. 详情正文、复习及相近表达中的内容说明继续只读 `userNote`；完整新增/编辑词条弹窗分别提供 `userNote` 的“说明”字段和 `pronunciationNote` 的“发音备注”字段，两个输入不得共享值或保存目标。除列表标题组件、详情独立发音行与完整词条编辑器外，其他区域不展示或改写 `pronunciationNote`。
9. `pronunciationNote` 只在列表卡片标题与详情弹窗独立发音行展示，并可在这两个组件及完整词条编辑器中维护；任一入口保存或删除后必须立即刷新两个视图。详情弹窗内操作不得关闭弹窗或改变当前词条。
10. 非编辑状态下不得用固定像素宽度提前截断黄色发音备注。列表标题组保持单行弹性布局，词条、读音、`＋` 和右侧状态/星级操作区保持稳定；备注在其间按内容自然伸展，KR 最长抵达右侧操作区左侧，JP 因专属 `krMeaning` Badge 最长抵达该 Badge 左侧。详情弹窗的红色读音与发音备注组件必须位于横跨弹窗正文全宽的独立第二行，备注使用除读音外的全部剩余宽度，不得被第一行状态、星级或关闭按钮挤压。两处都只在真实可用空间不足时显示省略号，末尾 `×` 始终保留。
11. 非空 `pronunciationNote` 与自定义 Tag `发音` 建立单向自动约束：新建或修改发音备注时必须去重加入该 Tag，并将 `pronunciationNote` 与 `tags` 一并纳入本地持久化和逐字段云同步；旧本地数据、IndexedDB 备用快照、导入数据及云端合并结果须全量追溯补齐。删除备注不自动删除 `发音` Tag，以免删除用户仍需保留的学习分类。
12. 完整新增/编辑词条弹窗在“发音 / 罗马音标注”与“中文释义”之间增加独立“发音备注”字段，最大 500 字符且无预置内容或占位文本。新建时必须为空；编辑时必须回填当前 `pronunciationNote`；保存时以字段内容替换旧值并触发既有自动 `发音` Tag、持久化、逐字段云同步和多视图刷新流程。不得继续使用固定空字符串清空已有发音备注。
13. 详情弹窗第一行只承载返回、词条标题及右侧状态/星级/关闭操作；第二行只承载红色读音和发音备注组件；第三层正文从词性与释义开始。第二行必须位于 `.modal-header` 内并横跨两列，以保持与标题操作区独立且在移动端仍占满可用宽度。详情内的发音备注 `＋` 不得继承列表卡片为压缩标题行设置的 `margin-left: -5px`，必须在详情作用域覆盖为 `margin-left: 0`，从而完整保留第二行自身的 8px `gap`。
14. 详情弹窗无返回历史时，词条标题、第二行红色读音、词性标签和内容说明使用同一条可见左边线。显示返回上一词条按钮时，词条标题会被按钮及其间距向右推移，此时第二行红色读音和发音备注整行必须同步增加相同缩进，与词条正文左边线继续对齐；返回按钮消失后必须移除该缩进。词性释义行取消额外背景卡片、左侧强调边和左内边距，避免正文第一行在常规状态下产生孤立缩进；该规则在 KR/JP 两端完全镜像。
15. 列表卡片与详情发音行进入原位编辑状态后，编辑槽必须从读音/加号之后弹性扩展到当前行右侧边界；列表以“学习中/已掌握”及星级操作区左侧为边界，详情以独立发音行右端为边界。列表标题组编辑态使用 `align-items: flex-end`，让单词、红色读音、`＋` 与输入框的可见下沿保持同线，不得使用 `flex-start` 使较矮的读音和输入框向上漂移。JP 专属 `krMeaning` Badge 在列表编辑期间临时隐藏，退出编辑后自动恢复，不参与争抢编辑宽度。编辑框使用软换行和内容驱动的自动高度完整展示文本，禁止出现会覆盖文字的横向或纵向滚动条；编辑结束后恢复原紧凑展示。
16. 详情弹窗顶部信息与长正文分离：标题操作区、独立发音行、词性释义、内容备注及 Tag/`+` 固定展示；例句与相近表达放入独立 `.detail-scroll-content`，且粉色滚动条从例句区域开始。`.detail-sheet` 与 `.detail-body` 均不得承担纵向滚动；详情重新打开或切换词条时的置顶、编辑器返回时的位置恢复、相近表达拖拽时的边缘自动滚动，必须统一操作 `.detail-scroll-content`。详情面板保持底部贴合，高度从 `85vh` 提升为带 `92vh` 回退的 `92dvh`，使顶部只保留约 8% 视口空间并扩大正文可视区域。
17. 完整新增/编辑词条弹窗的 `inputPronunciationNote` 改为与 `inputReading` 等高的单行文本输入框，继续保留 500 字符上限、空白新建、编辑回填与独立保存语义。表单仅将 `inputWord`、`inputMeaning`、`inputPartOfSpeech` 标记为必填：对应分组增加 `required-field`，标签增加“必填”胶囊，控件使用柔和玫红虚线边框并在聚焦时转为实线；所有可选字段维持普通边框，避免把“必填提示”误用为错误状态。
18. 完整新增/编辑词条弹窗必须让 `inputPronunciationNote` 与下方卡片标签草稿实时联动：输入值一旦非空，同一次 `input` 事件内即去重显示 `发音` Tag，编辑已有非空备注时打开弹窗也必须立即补齐该草稿标签。此联动只修改 `editingModalTags` 和标签 DOM，不得在点击“保存”前改写 `this.words`、localStorage、IndexedDB 或云同步待办；正式保存仍沿用既有的原子持久化流程。为遵守“删除备注不自动删除分类”的既有决策，已经加入草稿的 `发音` Tag 不因随后清空输入而被隐式移除。

## 验证

- 静态测试校验字段隔离、列表编辑态单词/读音/`＋`/输入框底边对齐、详情独立第二行结构与整宽布局、详情 `＋` 取消负偏移并与读音保持 8px 间隔、详情面板 `92vh`/`92dvh` 高度与紧凑顶部留白、标题/读音/词性/说明左边线统一、原位输入框弹性宽度/软换行/自动增高/无滚动条、`＋` 空白追加、已有文字回填替换、完整编辑器发音备注单行等高控件、独立字段的排列/空白新建/回填保存、500 字符总长度约束、三个必填字段的胶囊与虚线边框提示、可选字段隔离、事件隔离、完整编辑器标签草稿的 `input` 事件实时联动、`发音` Tag 自动补齐和持久化调用。
- Selenium 在 KR/JP 两端预置不同的 `userNote` 与 `pronunciationNote`，分别在列表标题和详情独立发音行执行点击 `＋` 新建/追加、点击已有备注回填修改、点击 `×` 删除，并确认两个视图实时同步、`＋` 的 pointerdown 不改变 DOM 且随后 click 只打开原位编辑器而不打开详情弹窗、列表编辑框右端抵达右侧状态操作区左侧且不重叠、长文本自动换行增高且无可见滚动条、详情编辑期间弹窗保持打开、详情读音行位于标题行下方且词性释义上方、整行跨越弹窗可用宽度、详情面板高度约占视口 92% 且顶部留白约为 8%、常规状态标题/读音/词性标签/说明左边线误差不超过 1px、显示返回按钮时词条与读音左边线误差不超过 1px且返回后恢复常规对齐、黄色备注与删除控件只在 click 阶段改变 DOM、长备注不会被固定宽度提前截断、旧备注及新备注均自动出现 `发音` Tag、删除备注后 Tag 保留、内容说明始终不变以及云同步同时追踪 `pronunciationNote` 与 `tags`；同时确认详情滚动条从例句区开始，滚动时词性、内容备注和 Tag 保持固定，重新打开/切换词条置顶及编辑返回位置恢复均操作新的正文滚动容器；完整编辑器中发音备注与读音输入框实测等高，且恰好三个必填控件显示胶囊和玫红虚线边框、可选字段保持普通样式；在不保存词条的情况下触发发音备注 `input`，标签草稿必须立刻显示 `发音`，同时词库和 localStorage 保持不变。

# ADR-010：相近表达卡片显示发音备注

- 状态：Accepted
- 日期：2026-10-10

## 背景

发音备注已经作为独立 `pronunciationNote` 字段显示在列表卡片和详情标题区域，但详情与复习中的相近表达卡片只显示词条和读音。用户在对比相近表达时无法直接看到已维护的发音提示。

## 决策

1. `renderSimilarBlockHtml()` 在相近表达的方括号读音右侧紧邻渲染非空 `pronunciationNote`。
2. 使用独立类 `.similar-word-pronunciation-note`，颜色与现有发音备注一致，并允许在标题可用空间内安全省略。词条、读音与备注统一使用 `1.25` 行高，所在的 `.similar-word-title` 使用文字基线对齐，不按各自盒子中心对齐。
3. 相近表达卡片中的备注只读，不增加编辑、追加或删除控件；编辑仍通过词条详情或完整编辑入口完成。
4. 空白备注不生成 DOM 节点，备注文本必须通过 `escapeHtml()` 转义。
5. 详情弹窗与复习背面继续共用同一渲染函数，KR/JP 双端结构、样式和行为完全一致。

## 验证

- 契约检查确认双端包含备注字段清洗、转义、紧邻读音的 DOM 与样式。
- 静态测试确认空值不占位、非空值使用只读节点。
- Selenium 分别在详情相近表达与复习相近表达中验证文字、位置、真实下沿误差与无编辑控件。

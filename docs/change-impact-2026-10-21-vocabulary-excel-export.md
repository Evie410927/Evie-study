# 变更影响分析：词库筛选导出 Excel

## 问题与完成标准

- 问题：现有 Header 没有可按学习状态或 Tag 选择范围的 Excel 导出入口。
- 用户可观察结果：点击新增图标后选择范围，下载带彩色粗体表头、四列内容和自动换行的 `.xlsx`。
- 明确不在范围内：不导出读音、备注、星级、全部例句或相近表达；不修改词库数据。
- 完成标准：KR/JP 双端入口、弹窗、筛选、文件内容与样式镜像实现，JP 保留专属韩文释义分行。

## 风险与回滚

- 数据兼容风险：只读导出，不改变现有数据；旧词条缺少字段时输出空单元格。
- 并发或跨设备风险：导出读取点击时的当前内存快照，不触发云同步。
- 安全与隐私风险：文件只在浏览器本地生成和下载，不上传第三方服务。
- 回滚方法：移除 Header 图标、导出弹窗和生成方法即可，不需要数据回滚。

## 验证计划

- 新增或更新的测试：双端 Header 顺序、弹窗筛选、Tag 多选、有效 `.xlsx` 结构、表头样式、四列与第一例句内容。
- 必须运行的质量门禁：`python scripts/run_quality_gate.py`
- 部署后验证：确认 GitHub Pages 的 KR/JP 页面均包含导出图标和 `.xlsx` 生成逻辑。

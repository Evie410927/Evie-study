# 变更影响分析：词库筛选导出 Excel

## 问题与完成标准

- 问题：现有 Header 没有可按学习状态、Tag 或星级选择范围的 Excel 导出入口，也不能主动调用系统“另存为”选择位置。
- 用户可观察结果：点击导出图标后可多选四星、五星等精确星级；八个列标题均显示复选框，单词、词性、释义、例句默认勾选且允许取消，发音、发音备注、说明、相近词汇默认不选；受支持的浏览器自动弹出系统“另存为”，不支持时直接下载，并生成带彩色粗体表头和自动换行的 `.xlsx`。
- 明确不在范围内：星级只用于筛选，不作为本次新增可选列；相近词汇不导出关联词除单词与中文释义外的任何内容；仍不导出第二组及后续例句；不修改词库数据。
- 完成标准：KR/JP 双端入口、状态/Tag/星级筛选、八列自由选择及零列拦截、自动保存位置分支且无可见开关、文件内容与样式镜像实现，JP 释义列保留专属韩文释义分行，相近词汇列只含中文释义。

## 风险与回滚

- 数据兼容风险：只读导出，不改变现有数据；旧词条缺少字段时输出空单元格。
- 并发或跨设备风险：导出读取点击时的当前内存快照，不触发云同步。
- 安全与隐私风险：文件只在浏览器本地生成和下载，不上传第三方服务。
- 回滚方法：移除 Header 图标、导出弹窗和生成方法即可，不需要数据回滚。

## 验证计划

- 新增或更新的测试：双端 Header 顺序、弹窗筛选、Tag/星级多选、八列复选框默认状态、取消默认列、零列拦截、相近词逐行精简内容、动态 XLSX 列范围、保存位置选择器成功/取消/不支持回退、表头样式与第一例句内容。
- 必须运行的质量门禁：`python scripts/run_quality_gate.py`
- 部署后验证：确认 GitHub Pages 的 KR/JP 页面均包含导出图标和 `.xlsx` 生成逻辑。

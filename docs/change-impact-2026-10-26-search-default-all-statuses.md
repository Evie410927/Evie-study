# 变更影响分析：搜索默认切换全部状态

## 问题与完成标准

- 问题：主状态停留在“学习中”或“已掌握”时，搜索会漏掉另一状态的匹配词。
- 用户可观察结果：输入非空关键词后自动选中“全部”，跨状态显示匹配结果。
- 明确不在范围内：不重置词性、Tag，不改变搜索字段范围或持久化数据。
- 完成标准：KR/JP 行为一致，清空搜索后仍保持“全部”。

## 风险与回滚

- 数据兼容风险：无，只改变内存筛选状态。
- 并发或跨设备风险：无。
- 安全与隐私风险：无。
- 回滚方法：回退本次提交，恢复搜索不改主状态筛选的行为。

- 部署后验证：在线 KR/JP 均包含 `activateAllMainFilterForSearch`。

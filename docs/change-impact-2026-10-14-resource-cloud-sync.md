# 学习资料云同步变更影响分析

## 问题与完成标准

- 问题：资料目前只存在当前浏览器，无法在同一云同步账号的设备间访问。
- 用户可观察结果：云朵弹窗可独立勾选“同步学习资料”；上传显示进度；其他设备同步后立即看到文件卡片，点击时下载并缓存；删除可跨设备传播。
- 明确不在范围内：资料内容全文检索、在线解析 Office、公开分享链接、资料版本历史。
- 完成标准：私有 Storage 与元数据 SQL 完整；KR/JP 镜像；旧本地文件安全迁移；失败不丢 Blob；按需下载；墓碑删除；测试与质量门禁通过。

## 影响范围

- [x] KR 应用
- [x] JP 应用
- [x] 数据字段或缓存迁移
- [x] localStorage / IndexedDB
- [x] 云端 payload / RLS / 版本协议（独立资料协议，不改词条协议）
- [ ] 列表 / 详情 / 复习 / 相近表达
- [x] 移动端与空状态
- [x] 现有规则或 ADR

## 风险与回滚

- 数据兼容风险：旧 IndexedDB v1 文件迁移为 pending；回滚旧前端仍可读取 `files` store 的 Blob，但不会识别云端占位记录。
- 并发或跨设备风险：稳定 ID、更新时间与墓碑阻止重复和复活；同 ID 的最新元数据获胜。
- 安全与隐私风险：私有 bucket、用户目录和 RLS 双重隔离；前端不含 service role。
- 回滚方法：停止调用资料云同步即可继续使用本地缓存；保留表、bucket 与 IndexedDB，避免删除用户文件。

## 验证计划

- 新增或更新的测试：SQL/RLS 静态检查；双端云同步选项；旧数据迁移；上传进度/重试；元数据优先；按需下载缓存；删除墓碑；失败保留待办。
- 必须运行的质量门禁：`python scripts/run_quality_gate.py`
- 部署后验证：线上 KR/JP 均显示资料同步选项；远端 commit 可追踪；数据库结构需执行更新后的 `supabase_vocab_sync.sql` 后生效。

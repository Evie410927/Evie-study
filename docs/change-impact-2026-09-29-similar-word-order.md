# 变更影响分析：相近表达卡片自定义排序

## 问题与完成标准

- 问题：相近表达只能按添加顺序展示，用户无法调整每张卡片的优先级。
- 用户可观察结果：详情与复习中的相近表达可直接拖动整张卡片排序，无新增按钮；刷新或重开后顺序保持。
- 明确不在范围内：不改变关系的双向建立/删除规则，不参与复习出卡排序，不恢复自动相似推荐。
- 完成标准：KR/JP 双端、详情/复习双视图、鼠标/触屏均可排序并持久化，卡片内部按钮保持原功能。

## 影响范围

- [x] KR 应用
- [x] JP 应用
- [x] 数据字段或缓存迁移（复用现有有序数组，无格式迁移）
- [x] localStorage / IndexedDB
- [x] 云端 payload / RLS / 版本协议（复用现有字段同步，不改表结构）
- [x] 列表 / 详情 / 复习 / 相近表达
- [x] 移动端与空状态
- [x] 现有规则或 ADR

## 风险与回滚

- 数据兼容风险：无新词条字段；旧数据天然保留原添加顺序。
- 并发或跨设备风险：排序作为当前源词条的一次用户编辑走既有逐字段同步；反向词条顺序互不覆盖。
- 安全与隐私风险：无新增外部数据或权限。
- 回滚方法：移除整卡拖拽事件和排序方法，保留原有 `manualSimilarWordIds` 内容与关系。

## 验证计划

- 新增或更新的测试：整卡无手柄拖动、触屏长按入口、控件隔离、详情排序、复习排序、本地持久化、重绘保持、双端镜像。
- 必须运行的质量门禁：`python scripts/run_quality_gate.py`
- 部署后验证：确认 GitHub Pages 两端包含 `startSimilarWordSort`、`startSimilarWordTouchSort` 和 `persistSimilarWordOrder`。

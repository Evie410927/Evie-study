# Excel 回导覆盖与版本回滚变更影响

## 问题与完成标准

- 问题：用户无法把本应用导出的 Excel 编辑后安全回导；错误表头可能导致字段错配，批量覆盖也缺少导入前回滚点。
- 用户可观察结果：Header 提供 Excel 导入图标；合法表格覆盖现有词条差异，非法表头整批拒绝；导入前版本显示在云朵入口的版本历史并可恢复本浏览器。
- 明确不在范围内：不从任意第三方表格猜测字段，不通过导入新增或删除词条，不自动上传云端，不让仅本地快照恢复云端。
- 完成标准：KR/JP 镜像实现；稳定 ID 与旧文件回退匹配正确；原子校验、快照、持久化和失败回滚通过真实浏览器测试。

## 风险与回滚

- 数据兼容风险：旧导出没有隐藏 ID，只能按唯一单词名匹配；任何歧义整批拒绝。
- 并发或跨设备风险：导入仅生成本机待上传修改，不绕过云端版本门禁；用户仍需点击云朵同步。
- 安全与隐私风险：限制文件和解压体积，只解析工作簿 XML，不执行公式、宏或外部链接。
- 回滚方法：云朵 → 版本历史 → 对“Excel 导入”选择“只恢复到本浏览器”。

## 验证计划

- 新增或更新的测试：严格表头、隐藏 ID、旧文件匹配、字段差异、例句、相近词、快照、失败原子性、双层持久化、仅本地恢复、KR/JP 镜像。
- 必须运行的质量门禁：`python scripts/run_quality_gate.py`
- 部署后验证：在线 KR/JP 均包含 `importExcelBtn`、`importVocabularyExcelFile` 与导入版本快照实现。

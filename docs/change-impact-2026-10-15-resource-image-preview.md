# 学习资料图片页内预览变更影响分析

## 问题与完成标准

- 问题：点击图片资料会打开新的浏览器页面，离开资料列表上下文。
- 用户可观察结果：图片在当前单词本页面的预览层中完整显示；点击右上角 `×` 后立即回到原资料列表。
- 明确不在范围内：PDF 页内阅读器、Office 在线解析、图片编辑和缩放手势。
- 完成标准：KR/JP 镜像；本地与云端懒下载图片均走页内预览；关闭后释放 Blob URL；HTML 导出不携带运行时预览内容；自动化测试与质量门禁通过。

## 影响范围

- [x] KR 应用
- [x] JP 应用
- [ ] 数据字段或缓存迁移
- [ ] localStorage / IndexedDB
- [ ] 云端 payload / RLS / 版本协议
- [ ] 列表 / 详情 / 复习 / 相近表达
- [x] 移动端与空状态
- [x] 现有规则或 ADR

## 风险与回滚

- 数据兼容风险：无数据结构变化；继续读取原 Blob 或按需下载后的缓存。
- 并发或跨设备风险：无同步协议变化；远端图片下载完成后才进入预览。
- 安全与隐私风险：仅使用临时 Blob URL，不写入导出 HTML，关闭时立即释放。
- 回滚方法：恢复图片走原浏览器打开路径，不删除 IndexedDB 或云端文件。

## 验证计划

- 新增或更新的测试：双端静态 DOM/方法契约；真实浏览器上传图片、点击页内显示、关闭回到列表、不触发新窗口、导出脱敏。
- 必须运行的质量门禁：`python scripts/run_quality_gate.py`
- 部署后验证：线上 KR/JP 都包含 `resourceImagePreviewModal`，图片点击不离开当前页面。
